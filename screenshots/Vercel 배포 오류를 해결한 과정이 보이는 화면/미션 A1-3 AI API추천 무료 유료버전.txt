미션 A1-3 AI API추천 무료 유료버전 

기획서 정말 잘 정리하셨네요! 특히 구현 범위를 명확히 좁히고(만성질환자 한 그룹), mock 처리할 부분을 구분한 게 아주 현실적이에서 좋습니다. 👍

이제 5단계 백엔드에서 쓸 AI API를 골라볼게요. **위험도 분류 결과에 맞는 자연어 안내 문구 생성**이 핵심 용도이니, 이 기준으로 나눠 정리하겠습니다.

---

## 1. 무료 버전 (비용 부담 없이 시작)

| API | 장점 | 단점 |
|---|---|---|
| **Google Gemini API** (gemini-1.5-flash) | 무료 할당량이 넉넉함(분당 요청 여유), 한국어 품질 좋음, 신용카드 없이 발급 가능 | 무료 한도 초과 시 제한 |
| **Groq API** (Llama 3.1 등) | 응답 속도가 매우 빠름, 무료 크레딧 제공 | 모델 성능이 GPT/Claude보다 약간 낮음 |

**추천: Gemini API (gemini-1.5-flash)**
- 미션·학습용으로는 이게 가장 무난합니다.
- 신용카드 등록 없이 API 키만 발급받으면 바로 사용 가능해서 초보자 진입 장벽이 낮아요.

---

## 2. 유료 버전 (품질·안정성 우선)

| API | 장점 | 추천 상황 |
|---|---|---|
| **OpenAI API** (gpt-4o-mini) | 자료·예제가 압도적으로 많음, 안정적, 저렴함(mini 모델) | 처음 유료로 넘어갈 때 가장 무난 |
| **Anthropic Claude API** (claude-3.5-haiku) | 긴 안내문·자연어 설명 품질 우수, 안전한 톤 생성에 강함 | 건강 안내처럼 신중한 어조가 중요할 때 |

**추천: OpenAI gpt-4o-mini**
- 유료지만 매우 저렴하고(안내 문구 생성 정도면 사실상 몇백 원 수준), 레퍼런스가 많아 막힐 때 검색하기 쉽습니다.

---

## 💡 이 미션에서의 결론

**Gemini(무료)로 시작 → 필요하면 gpt-4o-mini(유료)로 전환**을 추천합니다.

이유:
1. 미션 목적상 "안내 문구 생성" 정도는 무료 API로도 품질이 충분합니다.
2. 이전에 만드신 travel_planner.py에서 OpenAI를 쓰셨다면, 그 감각을 살려 OpenAI로 바로 가는 것도 좋습니다. (기획서에 언급된 API 연동 경험을 재활용!)

---

시작하기 전에 한 가지만 확인할게요. **travel_planner.py에서 어떤 API를 쓰셨나요?**
- 이미 OpenAI를 써보셨다면 → 그대로 OpenAI로 가는 게 학습 곡선이 가장 낮습니다.
- 처음이라면 → Gemini 무료로 시작하는 걸 추천드려요.
